# file-handling-and-exception

## 📖 Description
This Python program demonstrates how to:
- Read content from a user-specified file.
- Modify the content (by converting it to uppercase in this case).
- Write the modified content to a new file.
- Handle errors gracefully when a file doesn’t exist or cannot be read.

---

##  Features
-  Reads text from a file.
-  Modifies the content (converts to uppercase).
-  Writes the new content into a new file prefixed with `modified_`.
-  Error handling for:
  - File not found
  - File read/write errors

---

##  How to Use

1. Create a simple text file in the same directory (e.g. `example.txt`).
2. Run the program:
   ```bash
   filehandling.py
